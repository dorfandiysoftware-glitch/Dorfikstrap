# Dorfikstrap

A modern, open-source Android launcher for Roblox, written from scratch (Material 3).
Inspired by Bloxstrap and Chevstrap. Work in progress.

**Not affiliated with Roblox Corporation.** Dorfikstrap does not modify the Roblox client.

## Status

Version 0.1 is a diagnostic build: through [Shizuku](https://shizuku.rikka.app/) it shows which
Roblox folders the app can reach, to find out how client settings can be applied without
modifying Roblox.

## Building

`gradle :app:assembleDebug` (JDK 17, Android SDK). GitHub Actions builds every push.
